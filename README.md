# Tiny - Página web pequeña de Blogs  

Bienvenido a **Tiny**, un sistema web optimizado para la gestión y administración de contenido pequeño.  

![Tiny - Página web de Blogs](https://dbproject.rf.gd/assets/img/min-daam.png)

## 📌 Descripción  
Página web para Blogs, Panel administrativo avanzado con muchas funciones para la personalización de la página, extensiones y muchas otras cosas.  

## 📂 Instalación  
1. Descarga el código desde el repositorio **[tiny](https://github.com/armindeck/tiny)** o desde **[dbproject](https://dbproject.rf.gd/web/tiny)**.
2. Monta un servidor local o en la web con los archivos.   
2. Inicia sesión para acceder al panel administrativo.   
3. Modifica todo el contenido según tus necesidades.  
5. Listo!
