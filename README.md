# tiny
Tiny es una pagina web para publicar y compartir contenido de manera sencilla y rapida.

## Rutas en desarrollo

- [/home](/home)
- [/dashboard](/dashboard)

## Rutas en funcionamiento (dashboard)

- [information](/dashboard?sc=information)

## ⚙ Requisitos
- PHP 8 o superior
- Apache con mod_rewrite habilitado
- XAMPP, LAMPP u otro entorno web compatible
